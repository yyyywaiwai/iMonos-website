よくある質問 (FAQ)

トラブルが発生した場合や、解決しない手順についてはこちらをご確認ください。

年齢制限・インストールエラー
年齢制限に関わるエラーでインストールや起動ができません

以下のような症状が該当します：

  • 「install iMonos」を押しても何も起きない
  • 「このデバイスに設定されているコンテンツ制限により…」と出る
  • 起動時に「APP NAMEは年齢制限指定を超えています」と出る
  • 「The request install has a rating that exceeds this device’s restrictions」と出る
  • アイコンがグレーアウトして起動できない

【対処法】
1. 設定アプリ ＞ スクリーンタイム ＞ コンテンツとプライバシーの制限 に進む
2. 「App Store、メディア、Web、およびゲーム」 をタップ
3. アプリを一度 「18+」 に設定してから、再度 「Unrated」 に戻してください。

Tips 使わないときは「コンテンツとプライバシーの制限」自体をオフにしておき、アプリを起動する直前にオンにすることで、制限の切り替えがすぐに反映されない問題を回避できる場合があります。
リポジトリ追加
ソースを追加しようとすると「App transport error」が出る
URLが https:// で始まっているか確認してください。コピー時に末尾にスペースが含まれていないかもチェックしてください。
環境条件
AltStore PAL 自体がインストールできません

以下の条件をすべて満たしている必要があります：

  • iOS 26.2以上をインストールしている
  • (物理的に)日本国内に居住している
  • Safari経由でアクセスしている（Chrome等は不可）

※iOS 26.1以下の方は AltStore PAL を利用できません。パソコンを使用した「サイドロード」でのインストールを検討してください。

ダウンロードエラー
「アプリは利用できません」と表示される
アプリを配布しているサーバーが一時的に過負荷になっている可能性があります。数分待ってから再試行してください。

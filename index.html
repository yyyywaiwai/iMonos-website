iMons

Get yourself going.

Twitter保存ランキング系の非公式iOSクライエントです。新着/ランキングを素早く確認、任意のキーワードで検索、6種ソース(monsnode/twishare/Twidro/TwiVideo/JAVTWI/Twitter動画保管庫)のサポート。

Download iMons See Features
  • 最新フィードをリスト / グリッドで切り替え
  • 検索とランキングから目的の動画へすばやく到達
  • ダウンロード、お気に入り、アプリロック対応

Features

見たいコンテンツへ最短でたどり着ける機能を整理しました。

Browse

Home

最新の動画フィードをリストまたはグリッド（2〜8列）で表示。お気に入りのスタイルで閲覧できます。

Discover

Search

キーワードでタグやユーザーを検索。人気順・新着順でソートして、目的の動画をすばやく発見できます。

Track

Ranking

24時間・週間・月間・全期間のランキングをチェック。トレンドの変化を見逃しません。

Save

Download

ワンタップでダウンロード。通信状況に左右されず、オフラインでも快適に視聴できます。

Collect

Favorites

お気に入りのユーザーと動画を保存。後で見たいコンテンツを迷わず整理・管理できます。

Play

Player

サムネイルストリップでシークも簡単。ファイルサイズと再生時間を確認しながら再生できます。

Protect

App Lock

Face ID / Touch ID でアプリをロック。プライバシーを保ちながら安心して使えます。

Download

ダウンロードはこちら。

iOS26.2以上はAltstore PAL経由での単体インストール、それ以外の環境はipaをサイドロードしてください。
